# mono-store
RU:Одностраничный лендинг магазина одежды MONO на чистом HTML/CSS/JS — без сборки и зависимостей. Каталог с фильтрами и сортировкой, выбор размера, корзина с localStorage, промокод, оформление заказа с валидацией (демо-режим), плавные анимации и адаптив.
ENG:A single-page e-commerce landing page for MONO clothing store, built with vanilla HTML/CSS/JS — no build tools or dependencies. Features a product catalog with filtering and sorting, size selection, localStorage-powered cart, promo codes, validated checkout (demo mode), smooth animations, and responsive design.
